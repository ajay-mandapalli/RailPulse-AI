# RailPulse logo concept
Open preview.html in a browser to review the standalone concept.
Primary: existing forest #152017 and terracotta #AC512F.
Inverse: ivory #FAF8F5 and light terracotta #D88059, for forest backgrounds.
Mono: one-color forest.
All SVG files have transparent backgrounds. Wordmark lettering is outlined Segoe UI Bold, with no runtime font dependency.
The compact symbol is simplified for 16–32 px use; inspect preview at 100% browser zoom.
This folder contains concept assets only. Nothing is integrated into the application.
Approval is required before any integration.
